# Local account and bootstrap contract

The app and issuer use separate SQLite database files through Node.js built-in `node:sqlite`: ignored `.local/app/app.sqlite` and `.local/issuer/issuer.sqlite`. `src/db/account-store.mjs` creates their account tables with separate role checks and a unique normalized-username constraint. A local setup command will prompt for an app-admin username/password and a different issuer-admin username/password. Each password has at least 12 characters. The two services keep their accounts separate; each admin creates users only in their own service.

Usernames are trimmed, normalized with Unicode NFKC, then lowercased. Login lookup and uniqueness use only that normalized value. The database enforces uniqueness on it, and the initial app-admin and issuer-admin normalized names must differ. The exact allowed-character rule and length counting are pending. Password storage uses asynchronous Node.js scrypt with a unique 16-byte random salt per password, N=131072 (2^17), r=8, p=1, a 64-byte derived key, and a 256 MB memory limit. A stored string has the form `scrypt$N$r$p$salt$hash`; its salt/hash text encoding and accepted verification parameter range are pending. Verification uses `crypto.timingSafeEqual` and refuses out-of-range stored parameters before invoking scrypt.

Wrong username and wrong password return the same generic login error. An unknown username still triggers verification against a fixed dummy scrypt record. Login failures are limited per IP and normalized username: five failures in 15 minutes trigger a temporary lockout with increasing delay. Failures and lockouts are audit-logged, with unknown usernames redacted or hashed. The exact delay schedule and persistence rule are pending.

The bootstrap must preserve existing admins on rerun and never print or commit passwords, salts, hashes, signing keys, or service tokens. The account tables are implemented, but the interactive bootstrap and login routes are not; the remaining choices above are needed before those are written.
