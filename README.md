# ZK Access

Privacy-Preserving Eligibility Proof is a proposed local demonstrator. The repository contains the proposal, a [draft implementation plan](docs/implementation-plan.md), and the first age-policy, circuit, and credential-signing code slices. The team has selected an age-18 demo with a separate local mock issuer, browser proof generation with Circom/snarkjs/Groth16, and Node.js/Express/SQLite/cookie sessions/plain JavaScript for the app.

Start with the plan's **Decision register and remaining questions** section. The team has selected a signed salted commitment, Groth16, a 90-day credential lifetime, database-backed single-use challenges, and separate issuer-admin access. The issuer retains restricted credential metadata but no birth date, salt, or request body. The [contributor work packages](docs/work-packages.md) identify tasks the four members can begin now and tasks waiting on remaining decisions. The [test matrix](docs/test-matrix.md) gives synthetic age, credential, and replay cases; the [draft threat model](docs/threat-model.md) maps risks to mitigations and evidence.

Follow the [local setup guide](docs/setup.md) to generate local issuer/service credentials, run the app and issuer scaffolds, and verify the Circom/Groth16 artifacts. The current code calculates the public age-18 cutoff, validates issuer birth dates, enforces the agreed role matrix on every declared HTTP endpoint with audited `AUTH_DENIED` denials, calculates session deadlines, strictly parses private credential files and public verification requests, encodes Ed25519 signing bytes, and proves the age statement with synthetic inputs. Both services support login, persistent cookie sessions, CSRF-protected writes, user management, and an append-only audit log. The issuer issues and revokes credentials, and the app issues single-use challenges, verifies Groth16 proofs, lets the admin configure the age rule, exports sanitized reports, and purges data on the agreed retention schedule. Browser screens and in-browser proving are not built yet. Run `npm test` and `npm run zk:check` (Node.js 24 tested).
